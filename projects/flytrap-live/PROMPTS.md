# "A Venus flytrap can count": pictures for the frame-by-frame version

The frame-by-frame method brings real pictures to life, so it needs one picture per shot in your
style. Make them in the same app you used for the living-room picture, attach that picture to every
prompt (as the style and character reference), and stay in the same chat so the plant looks the same
in every shot. Then send me all 12. I'll animate each one, cut them to your narration
(`projects/flytrap-fact/voice.mp3`, 44 s) and add sound effects.

Format: vertical 9:16 for Shorts. For a 16:9 video, change "Vertical 9:16" to "Horizontal 16:9" in every prompt.
